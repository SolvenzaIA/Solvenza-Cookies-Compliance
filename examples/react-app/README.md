# Ejemplo React 18+ App - Acme Consent SDK

Aplicación React 18 con Vite demostrando la integración reactiva mediante hooks (`useConsent`).

## 🚀 Cómo ejecutar este ejemplo

```bash
# 1. Navegar a la carpeta del ejemplo
cd examples/react-app

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev
```
