# Ejemplo Next.js 14+ App Router - Acme Consent SDK

Aplicación Next.js 14 con App Router demostrando la estrategia `strategy="beforeInteractive"` en `layout.tsx` para garantizar consentimiento previo LSSI antes de la hidratación del cliente.

## 🚀 Cómo ejecutar este ejemplo

```bash
# 1. Navegar a la carpeta del ejemplo
cd examples/next-app

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev
```
