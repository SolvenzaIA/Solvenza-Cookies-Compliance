# Ejemplo Nuxt 3 — Solvenza Cookies Compliance

Este directorio contiene una aplicación de demostración de **Nuxt 3** que ilustra la integración con `@solvenza/cookies-compliance/nuxt`.

## Características

- **Soporte SSR Universal**: Funciones e hidratación segura sin errores de renderizado en servidor.
- **Componente Declarativo**: `<ConsentGate>` con slots `#default` y `#fallback`.
- **Composables Reactivos**: `useConsent()`, `useConsentService()`, `useGpc()`, `useSyncConsentLocale()`.
- **Botón Flotante de Revocación Permanente**.

## Ejecución local

```bash
npm install
npm run dev
```
