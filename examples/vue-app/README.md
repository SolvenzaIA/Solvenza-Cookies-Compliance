# Ejemplo Vue 3 & Nuxt 3 — Solvenza Cookies Compliance

Este directorio contiene una aplicación de demostración de **Vue 3** y **Nuxt 3** que ilustra la integración con `@solvenza/cookies-compliance/vue` y `@solvenza/cookies-compliance/nuxt`.

## Características demostradas

- **Composables Reactivos**: `useConsent()`, `useConsentService()`, `useConsentLocale()`, `useGpc()`.
- **Sincronización Reactiva de Idioma**: `useSyncConsentLocale()`.
- **Componente Declarativo**: `<ConsentGate>` con slots `#default` y `#fallback`.
- **Botón Flotante de Revocación Permanente**.

## Ejecución local

```bash
npm install
npm run dev
```
